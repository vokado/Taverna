# Контракт этапа09 — миры, сценарии, события

REQ-ID WORLD-001–007/009, COMP-005, CTX-001/004/006, MEM-006; подготовка WORLD-004/005/007 для режиссёра10 и WORLD-008 для RPG11. D-09/10 утверждены. Контракт не означает готовность: фактические результаты в reports/STATUS.md.

Мир и сценарий — версионированные JSON templates с UUID; история содержит собственный снимок выбранных версий, последующее редактирование шаблона историю не меняет. Сценарий ссылается на мир; сцена задаёт локацию, время и участников. Подключение к действующей истории — явное подтверждённое действие с CAS; повторное подключение поверх существующего мира отклоняется, вместо молчаливой потери состояния. Ветви копируют/восстанавливают собственное состояние и журнал событий вместе со snapshot.

Мир содержит сущности (география/места/фракции/персоны/ресурсы/культура/история), связи, лорбук, календарь и декларативные правила. Сценарий содержит premise/цели/возможные начала, настройки и собственные правила; цели не принуждают игрока следовать маршруту. Случайный старт выбирается воспроизводимым seed, результат сохраняется. Генерация моделью — типизированное предложение с preview, проверкой ссылок и явным подтверждением; никаких команд ОС, eval или прямой записи модели.

Календарь имеет именованные месяцы с длинами и заданные длительности часа/дня, время хранится целым числом игровых минут. Пропуски ограничены, не запускают бесконечную фоновую генерацию. AST условий: all/any/not, сравнения и exists, только разрешённые пути clock/flags/resources/entities. Ограничены глубина, число узлов, длина списков. Эффекты: flags/resources/локация сущности/атрибуты/сюжетные линии. Последствия применяются в памяти к копии, затем публикуются одной storage-транзакцией. Ошибка любого эффекта отменяет весь event. Правила вычисляются в фиксированном порядке один раз на событие, без рекурсивного запуска; постоянные условия не дают неконтролируемых циклов.

Event UUID/idempotency + fingerprint предотвращают повторные эффекты; тот же ID с другим содержимым —409. Журнал содержит исходную ревизию, причину, источники/причины, изменения до/после и результат правил. Поздние model jobs требуют точного story/branch/revision. Ручное исправление — новое событие, прошлое сохраняется. Object truth не означает NPC knowledge: лор фильтруется по явным доступам до триггеров/бюджета; приватное состояние мира целиком не сериализуется в prompt.

Одна существующая очередь служит всем тяжёлым операциям. Один локальный post-message event bus заменяет одиночный callback, сохраняя подписку памяти. Его уведомления не подменяют atomic publication: критические изменения рассчитываются до транзакции или отдельным CAS-событием. Ошибка вспомогательного подписчика не отменяет сохранённую реплику, возвращается явным диагностическим результатом.

Собственный пакет JSON содержит version/data/hash и исходные ID, preview предупреждает о конфликтах/неподдерживаемых расширениях. Lorebook SillyTavern импортируется отдельным адаптером с сохранением оригинальных данных и отчётом о неподдерживаемых механизмах. Противоречия не игнорируются. Схемы v1 не меняют старые ветви без мира. Ошибки: invalid_world/rule/effect, world_missing/scenario_missing, world_already_attached, branch_conflict, event_conflict, world_state_conflict, lore_import_invalid. Проверки: два независимых прохождения, изменение template, прошлое fork, повтор/конфликт ID, rollback, bounded AST/unsafe paths, календарь/переходы, знание до lore triggers, imports roundtrip, browser forms, real AI отдельно BLOCKED.

## Реализованные форматы и правила

World/Scenario v1: world_models.py; world_templates/scenario_templates регистрируются в JsonStore. Записи хранятся в worlds/{UUID}.json и scenarios/{UUID}.json. Сценарии проверяются против мира, редактирование мира не может оставить сломанные ссылки сценария. Общий JSON-catalog с CAS защищает также от вставки нового сценария между чтением и записью. Он не является отдельной очередью или СУБД. Снимок мира содержит исходные envelopes и выбранное начало/seed; template-изменения его не меняют. Описание начала явно общедоступно и входит в scene/context; скрытый замысел/цели не выдаются всем NPC.

Время исправляется отдельным set_clock-событием с причиной и сохранением прошлого, обычный пропуск — time_advance. Правила проверяются по порядку, могут учитывать последствия предыдущих правил этого события, не запускаются рекурсивно. Повторяемые правила имеют cooldown в игровых минутах; изменение часов назад не стирает историю срабатываний. Вне сцены перемещаются/меняют ресурсы сущности по этим правилам. Модельные решения NPC и режиссёра подключаются в10, не объявлены завершёнными этим reducer.

События реплики и изменения мира публикуются атомарно с сообщением через state_reducer; ошибка последствия не публикует реплику или часть изменений. Между репликами применяется согласованная семантика06: последствия текущего эпизода закрепляются за его последней репликой до добавления следующей. Для точной промежуточной точки используется checkpoint. Fork сохраняет ID событий/исходные fingerprint как происхождение, переносит локальные branch/source links и origin; исходные снимки не меняет. EventBus только уведомляет подписчиков после публикации, не создаёт вторую очередь.

Лор доступен только public/knower_ids, затем срабатывают обычные casefold-подстроки и selective AND вторичных ключей; рекурсивной активации нет. Общий budget блока lore прозрачен в инспекторе. Импорт SillyTavern сохраняет original, regex/вероятностные и альтернативные логические механизмы отключает с предупреждением; размещение/рекурсию/задержки не объявляет точно совместимыми. Реальный corpus остаётся отдельной проверкой.

Пакет мира — JSON format=taverna-world/version1/data/sha256, включает шаблоны мира и сценариев. Импорт создаёт собственные ID из хеша, сохраняет provenance/extras, не перезаписывает старые шаблоны; повтор безопасен. Пакет истории — ZIP format=taverna-story/version1 с manifest.json, documents/NNNNNN.json и assets/SHA.bin. Manifest сопоставляет logical keys и хеши; импорт не извлекает произвольные пути. Он проверяет весь story/branch/state/message/ref graph и публикует одним commit. Все ветви/неизменяемые снимки/память/мир/RPG в состоянии сохраняются; PNG-портреты включены. Другие медиа расширяет адаптер12, экспорт не выдаёт неполный пакет молча. Лимиты сейчас: ZIP16МиБ, распакованные данные64МиБ,10000 файлов; ZIP bomb/дубликаты/шифрование/symlink/путь/неожиданные документы отклоняются. Хеш защищает целостность и согласование preview, не является подписью доверенного издателя.

ID истории сохраняются; отличающиеся локальные ID дают явный конфликт, без замены. Совпадающие документы переиспользуются под read guards; новые публикуются с CAS. Счётчики ревизий нового локального хранилища начинаются заново; исходные revision/updated_at сохраняются в JSON receipt импорта. Назначение профиля истории и доступные профили сообщений включаются, глобальные/служебные/персонажные назначения остаются целевой установкой. Задания, диагностические запросы и редакторские черновики не являются историей и не экспортируются этим пакетом; полная резервная копия приложения — этап15. После неуспешного CAS могут остаться неизменяемые невидимые медиа-объекты, но не частично опубликованная история.

Редакторы: формы сущностей/связей/ресурсов/календаря/лора/начал/правил, проверяемый JSON и независимые JSON-черновики с CAS. Незавершённый raw не заменяет модель формы; при сохранении формы отдельная raw-редакция остаётся в черновиках. AI-мастер работает в общей очереди, создаёт валидируемое предложение, подтверждение и template/proposal status публикуются атомарно; source revision guard отклоняет поздний результат. Отсутствие живой модели не подменяется синтетическими данными.
