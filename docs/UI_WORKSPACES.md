# UI и рабочие пространства

Реализованы главная страница с фактическими счётчиками локальных данных, подключение LM Studio, сохранённые ответы, проверка JSON, страницы настроек и менеджер панелей. Отсутствующие модули персонажей/историй не имитируются; соответствующее пустое состояние честно отмечено. Конечные library/chat/context/character/world/relationship панели добавляются вместе с доменами 05–10; полный UI-001–012 пока не принят.

Настройки хранятся в config/settings.json через JsonStore (логический ключ), рабочие пространства — отдельные JSON-документы config/workspaces/UUID.json. Отсутствующие настройки используют default в памяти, не выдают успешный save. PATCH с expected_revision не перетирает конкурентную вкладку: 409 сохраняет предыдущую публикацию и показывает ошибку; автоматический blind retry не выполняется. UI отображает saving/saved/error и позволяет перечитать данные. Экспертные значения сохраняются при смене уровня; при явном сохранении нового экспертного JSON можно удалить отдельные ключи. Внешние URL в цветах отвергаются схемой.

Три темы + custom palette, font/size, simple/advanced/expert, economy без удаления данных. Палитра/шрифт применяются CSS variables; remote fonts не загружаются. Текущий economy отключает эффекты; адаптивные ИИ-профили будут связаны с scheduler в соответствующих модулях. Не обещается, что настройка уже регулирует несуществующие director/memory jobs.

Панели models/history/storage имеют order/width/collapsed. Доступны drag/drop и обычные кнопки перемещения; resize через range с клавиатурой/мышью, collapse через кнопку. Layout публикуется JSON транзакцией отдельно от будущих story state. Новое пространство копирует layout, а не данные истории. Immersion уменьшает навигацию, оставляет явную кнопку выхода/завершения. Настройки и layout восстанавливаются после restart/reload.

Доказательства: tests/test_settings.py, существующие security/storage/generation tests, app/web/e2e/bootstrap.spec.ts. E2E проверяет expert→simple→expert без потери seed, сохранение темы/reload, workspace create/collapse/reload, ширины 1920/1280/640, явное shutdown. Это не проверка всех будущих режимов чата или полного дизайна релиза.
