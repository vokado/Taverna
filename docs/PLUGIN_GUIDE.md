# Расширения: руководство текущей внутренней сборки

Этап14 ещё не завершён. Работают установка/права, явный запуск, просмотр и подтверждение внутренних изменений, передача выбранных внешних файлов. Внешняя запись, сеть, команды, правила и планировщик ещё разрабатываются. Это не официальный релиз1.0.

## Установка и разрешения

1. Откройте «Расширения», выберите локальный ZIP и нажмите «Проверить пакет без запуска».
2. Просмотрите название, версию, совместимость, зависимости, список файлов, checksum и запрошенные возможности. Установка не скачивает зависимости.
3. Подтвердите установку. Пакет устанавливается выключенным, без прав; его код не запускается.
4. Откройте пакет. Отдельно выберите каждое разрешение и его области: ключи собственных записей, UUID документов/`new` для создания, определённые локальные каталоги. Изменение прав требует подтверждения. Включение только разрешает последующий явный запуск.

Недоверенный исполняемый модуль работает в ограниченном WebAssembly runtime. Python разрешён только как доверенный код с полным доступом к файлам, сети, командам и данным пользователя. Отдельный процесс и список прав не превращают такой Python в песочницу. Предупреждение привязано к SHA256; обновление пакета сбрасывает доверие и права. Каждый ручной Python-запуск дополнительно подтверждается. Отзыв не отменяет уже совершённые им действия ОС.

## Запуск и внутренние изменения

Заполните объявленные поля, при необходимости выберите конкретные заметки, рукописи или собственные записи расширения. Разрешение чтения не заменяет разрешение записи. Заметки не дают доступа к шаблонам с их разрешениями; память и знания NPC автоматически не передаются.

Нажмите «Вычислить план расширения». Задачу можно остановить. Подготовленный план сам не изменяет JSON. Просмотрите действия и подтвердите перечисленные изменения или отклоните план. Применение внутренних данных и запись результата атомарны; повторное подтверждение не создаёт дубликат. История планов доступна после перезагрузки.

Если исходный документ/права/код/каталог расширений изменились, старый план может быть отклонён. Перечитайте опубликованные права и вычислите новый план. Не пытайтесь вручную перебазировать номер ревизии старого результата. Удаление и повторная установка пакета не оживляют старые разрешения или планы.

## Выбранные внешние файлы

Для передачи файла нужно отдельное `filesystem.read` на существующий локальный каталог вне папки программы/данных и её предков. UNC, сетевые диски, перенаправления/symlink/junction, жёсткие ссылки, устройства и пути с переходами не допускаются. Короткое DOS-имя каталога сопоставляется с полным физическим путём; его подмена или переход за разрешённую область блокируются. Имена с пробелами и кириллицей поддерживаются.

В разделе запуска выберите выданный каталог, введите относительное имя файла и нажмите «Проверить внешний файл». Просмотрите размер, SHA256 и текст, если это UTF-8. Для бинарного файла показываются сведения без текстового просмотра. Подтвердите передачу снимка и добавьте проверенный файл к запуску. До запуска можно убрать его из списка.

Разрешено до8 файлов, максимум128КиБ на файл; все данные и параметры вместе ограничены256КиБ. Если содержимое изменилось после предпросмотра, запуск блокируется: уберите файл, проверьте его снова и подтвердите новый checksum. В плане сохраняются путь/размер/hash прочитанного снимка. Последующее редактирование исходного файла не меняет уже проверенный результат; подтверждение плана не записывает ничего во внешний файл. Эти снимки не добавляются в память NPC автоматически.
