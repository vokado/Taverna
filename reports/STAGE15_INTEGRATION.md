# «Таверна» 1.0 — интеграция мастера обновлений (17.11.2026)

## Сделано в этой ветке

- Перенесены из ранее подготовленного этапа 15 безопасное обновление в НОВЫЙ каталог и отдельный GUI/CLI updater.
- Проверяются состав ZIP, допустимые Windows-пути, случаи ZIP traversal/ссылок, повторы имён и файлово-каталожные конфликты с учётом регистра.
- Имена ZIP дополнительно проверяются по сырым local headers: Windows zipfile может нормализовать обратные косые черты.
- SHA-256 проверяется до копирования; регистр шестнадцатеричных символов и пробелы вокруг digest нормализуются.
- Перед публикацией новой копии создаётся полный проверенный backup, копируются данные, проводится проверка JSON integrity.
- Запрещены обновление поверх старой установки и обновление при захваченной блокировке запуска.
- Добавлены восстановление из полного ZIP, отдельный no-console Windows Taverna-Updater.exe и справка.
- Все docs/*.md теперь включены в portable, поскольку README ссылается на USER_GUIDE, API и LM_STUDIO.
- Frozen smoke дополняется проверкой updater, установки в новую папку, целостности старого EXE и отдельного восстановления.
- Добавлен fail-closed documentary gate scripts/release_gate.py для 181 строк матрицы и тесты на неполные доказательства.

## Почему не объявлено успешным

Этот отчёт фиксирует изменения кода, но НЕ утверждает, что тесты текущего HEAD прошли. Перед слиянием необходимо проверить завершённые Ubuntu/Windows Actions одного и того же HEAD, Windows packaged EXE и frozen smoke, затем выполнить остальные приёмочные процедуры этапов 14–16.

Ближайший известный CI старой updater-ветки, 43956658117: Ubuntu провалил Ruff import ordering при 419 прошедших pytest; Windows обнаружил ошибку backslash-имени в тесте и независимый flaky stream idle test. Исправления импорта и raw-name проверки подготовлены здесь, повторный CI ещё не подтверждён.

Проверки на целевой Windows 11, локальном LM Studio с моделью, RTX 5070 и реальном корпусе пользовательских данных НЕ ВЫПОЛНЕНЫ. Нельзя считать весь продукт 1.0 выпущенным до подтверждённой приёмки.
