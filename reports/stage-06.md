# Этап 06 — чаты, группы, ветви

2026-11-15. Реализованы независимые stories/card snapshots, Scene/participants/order, scoped state snapshots и bounded message segments; три представления чата, страницы/поиск, edit/delete через новые ветви, branch tree/compare, главы/закладки/named checkpoints/restore, loaded-only chat/group generation, swipes/continue/fragment regeneration, partial explicit apply и защита поздних результатов. Добавлены JSONL/JSON chat import с preview и выборочный перенос записей событий с provenance, без распространения памяти.

Контракты/инварианты: docs/CHAT_AND_BRANCHES.md и chat_schemas.py; неизменяемые источники ТЗ сохранены. Архитектура не заменена. В реализации исторические state pointers сохраняются внутри bounded message segments, а не отдельным файлом на каждую реплику: сохраняется точность nested forks и уменьшается рост manifest. State.scene хранит присутствие/очередность вместе с миром/памятью; UI metadata зеркалируется атомарно.

Проверки включают tests/test_chat.py, test_chat_import.py, test_transfers.py и всю предыдущую регрессию. Проверены: повторная регенерация не создаёт второй fork; nested fork не видит future fact; edit/delete сбрасывают старые последствия и сохраняют оригинал; checkpoint restore не затирает текущую линию; late model result не пишет в изменённую ветвь; group NPC→NPC без user impersonation; order не сбрасывается при view change; partial apply идемпотентен; импорт сохраняет metadata/даты, требует author mapping; transfer не меняет source revision и не распространяет knowledge/world effects; storage read guards отвергают изменённый источник. Дополнительно выявлен/исправлен dead-worker риск повторного исполнения старой in-memory очереди после storage failure; durable jobs прерываются, stale queue сбрасывается, тест подтверждает отсутствие replay.

Browser: bootstrap/workspace/cards/autosave regression + отдельный chat flow (без модели), где проверяются создание, authored greeting, user message, три режима, правка в альтернативе, возврат к оригиналу/reload и bounded DOM. Ошибки e2e locators исправлены по trace: ожидание persisted message ограничено chat-messages, а не полю редактирования с тем же текстом; ветка проверяется polling toHaveValue, не мгновенным inputValue. Сохранение данных не имитировалось.

Сборка: во внутренние ZIP добавлен collector CPython/Python/npm runtime notices и checksum manifest (40 пакетов/runtime entries на Linux). Это первичный комплект уведомлений, не окончательный юридический аудит полного release bill of materials. Проверки frozen Windows выполняются CI на новом коммите; до результата этот код не получает Windows PASS. CI предыдущего adc8193: run 43639176196 SUCCESS с native Windows smoke.

Открыто: живой LM Studio/RTX5070, реальные сторонние карты/чаты, полный quality/context/memory/world/director/media функционал зависимых этапов. Полные CHAT/CHR/COMP родители не закрываются по одному позитивному сценарию. Новые corpus ограничения отражены в docs, исходные неизвестные swipes/расширения не потеряны. Итоговый 1.0 не готов.
