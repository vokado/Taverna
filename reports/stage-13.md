Принятие не ребазирует устаревший результат; отказ/отмена/ошибка не меняет оригинал. Chat→prose создаёт отдельную книгу, исходные сообщения/ветвь/память/RPG не изменяются. UI проверил полный цикл. Неподдержанное EPUB-аудио отклоняется до выдачи результата; WebP → PNG. История версий не читается при открытии списка рукописей; отдельный тест проверяет только current document reads и порции.

MED-008: library/documents immutable checksum файлы, versioned JSON metadata/описания/теги/поиск/архив/явные ссылки на мир/историю/ветвь/сцену/событие/сообщение. UTF-8 TXT/MD/JSON и ограниченный DOCX имеют безопасный текстовый preview; PDF проверяется структурно pypdf, без встроенного active viewer/полнотекстового извлечения. Downloads attachment. TOOLS-001–003: заметки/словарь/закладки/поиск/архив/настраиваемый seeded name generator с JSON журналом, пользовательские шаблоны с объявленными переменными, preview и отдельными notes.write/manuscripts.write grants. Изменение/отзыв блокирует старый preview; подтверждённый эффект+receipt атомарны, повтор не дублирует запись. Недопустимый текст новой главы вызывает422 без изменения рукописи или потребления preview. Редактор событий переиспользует настоящий StoryWorld/world reducer и branch CAS.
