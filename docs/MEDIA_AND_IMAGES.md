# Медиа, сцена и локальные изображения

Этап12: MED-001–009, CHR-006, UI-007/009/011, NFR-005/006, части COMP/STOR. Доступные автоматические проверки пройдены; аппаратная приёмка BLOCKED. Полный релиз1.0 не готов.

Библиотека импортирует PNG/JPEG/WebP/GIF/APNG и WAV/MP3/Ogg/FLAC, проверяет сигнатуры/содержимое/checksum, сохраняет неизменяемый файл и версионированные JSON-метаданные. Есть категории, описание, теги, поиск, порции50, миниатюры, предпросмотр и архивирование с сохранением исторических ссылок. Первичные данные — JSON, бинарные ресурсы — отдельные файлы, SQLite не добавлен. Активные SVG/HTML не обслуживаются как изображения. Лимиты:12МиБ на файл,16Mi pixels/кадр,32Mi pixels суммарно,256кадров; параметры — проверенные ограничения, не аппаратный SLA. TinyTag проверяет структуру аудио; это не обещание полного декодирования любого испорченного потока. Chromium проверяет фактическое воспроизведение собственных тестовых образцов.

Композиции и привязки NPC/сцена/событие/мир изолированы в branch-state. Слои: фон/персонажи, костюм/поза/эмоция, положение/размер/прозрачность/z/fit; варианты выбираются по конкретности/приоритету. Отсутствующие NPC скрываются. Свет, дождь, туман, виньетка, переходы, музыка и окружение имеют отдельные переключатели. Economy/reduced-motion заменяет анимации статическими миниатюрами. Аудио запускается явной кнопкой, останавливается при уходе/скрытии/отключении. Выключение композиции не изменяет литературный чат. Raw-редакторы и автосохранённые черновики отделены от публикации с CAS. Story ZIP переносит текущие и исторические ресурсы всех ветвей, проверяет пути, сигнатуры и ссылки; неполный пакет не выдаётся.

## Генератор

Реализован кандидат `comfyui-modern-v1`: числовой HTTP loopback, без proxy/redirect/DNS, ограниченные ответы. Современный ComfyUI обязан поддерживать `/api/jobs` и атомарную адресную отмену `/api/jobs/{id}/cancel`. Проверка capabilities читает system_stats/object_info и отправляет отмену случайного неизвестного UUID (ожидается cancelled=false); workflow не создаётся. Устаревший движок получает понятную ошибку. API исследован по Comfy-Org/ComfyUI `server.py` и `comfy_execution/jobs.py`; реализация дополнительно требует реальных испытаний совместимости.

Используется фиксированный стандартный checkpoint workflow из шести типов узлов, batch1, UUID output prefix. Checkpoint/sampler/scheduler выбираются из действительного каталога движка. Произвольные workflow/custom-code узлы не исполняются. Веса и движок устанавливает владелец отдельно. Официальный выбор движка/режима D-06 отложен до технических испытаний; установка ComfyUI не обязательна для чата/библиотеки. Другие внешние архитектуры workflow требуют собственного адаптера, не выдаются за поддерживаемые.

Генерация запускается только явной кнопкой, выполняется в единой JobQueue; LM Studio не получает lifecycle-запросов. Настраиваются checkpoint, prompts, sampler/scheduler, CFG/steps/seed/размер/категория/теги, источник истории. Источник — provenance, не автоматическое раскрытие NPC-контекста. Готовый PNG проверяется и добавляется в галерею; привязка к сцене — явная операция. Поздний результат не изменяет другую ветвь или ревизию.

JSON lease с собственным UUID фиксируется до POST/prompt. Неизвестный результат после потери связи/перезапуска сохраняет блокировку новых управляемых GPU-задач до адресной проверки. Отмена HTTP не считается остановкой движка; отправка дожидается подтверждения UUID, затем выполняется scoped cancel и проверка терминального статуса. Исчезновение pending-job подтверждает отмену только при предварительно наблюдавшемся pending и cancelled=true. Никаких глобальных interrupt/free/unload запросов нет. Восстановление завершённого результата идемпотентно, повторного POST/prompt нет. Ручное снятие lease требует отдельного подтверждения и причины после самостоятельной остановки движка, записывается как manually_released, не технически подтверждённый terminal.

Сериализация распространяется на собственную очередь и вложенные AI-вызовы. Внешние программы могут занять GPU независимо. Порог свободной VRAM — проверка snapshot, не гарантия от OOM; загруженная LLM остаётся в памяти. После terminal движок может удерживать свой кеш. UI показывает состояния/ошибки, подтверждённые результаты и неизвестность диагностики, без фиктивного процента прогресса.
